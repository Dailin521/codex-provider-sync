# v1.0.0：Windows Electron 正式版

本次提供 Windows x64 安装版和便携版。重点是：切换 Provider 后，帮助因 Provider 信息不一致而无法使用的旧会话重新可用，而不是恢复列表可见性。

## 下载与安装

- 推荐安装版：`CodexProviderSync-1.0.0-windows-x64-setup.exe`。
- 便携版：`CodexProviderSync-1.0.0-windows-x64-portable.zip`，完整解压后运行 `Codex Provider Sync.exe`，不要只复制 EXE。
- 下载以 [v1.0.0 Release](https://github.com/Dailin521/codex-provider-sync/releases/tag/v1.0.0) 为准，附 SHA-256、SBOM 和安装包验收文件。

**本版未签名，Windows 可能显示发行者/SmartScreen 提示。请核对官方仓库下载及 SHA-256。** 本版采用手动安装更新，不自动下载、覆盖或重启安装。Electron 的每日首次启动检查/手动检查可以打开新版下载页。

**旧 v0.4.1 Windows .NET 的更新按钮不能完成迁移。** 它可能提示存在 1.0.0，但点击更新会因旧资产不存在而失败。请直接下载安装版或完整解压便携包；不要把安装器改名成旧 `CodexProviderSync.exe`。旧程序和旧备份不会由本次发布删除。

## 主要变化

- 新版双语桌面界面：概览集中同步与切换，支持直接同步和预览后确认；完成通知可点击关闭。
- 统一备份入口，默认保留最近 2 份；只为实际改动创建备份，提供手动恢复。
- 聊天按项目与父子任务展示，列表/正文独立滚动，右键复制会话 ID、继续命令；正文按需读取。
- 操作日志提供独立详情，记录数量、结果、备份和分项耗时。
- 自定义 Codex/SQLite 存储配置；高级诊断与专项修复独立于普通同步，并显示进度。
- 符合条件的等 UTF-8 字节长度 Provider 使用原地更新；不等长时流式复制未改变的正文。保留备份、占用检查、落盘与文件时间戳恢复。

## 使用与限制

1. 在概览确认存储路径、当前 Provider，先预览或直接同步。
2. 如果只完成一部分，查看日志；结束占用会话后重试，或从“备份 / 恢复”撤销。
3. 普通同步不修复模型、工作目录、消息或历史索引。专项修复仅在确有需要时主动选择。

同步不处理登录/账号，也不能解密另一 Provider 或账号的旧加密内容；不保证所有旧会话都能继续或 compact。等长原地更新仍有每文件落盘成本，不能理解为数千会话瞬间完成；本次没有取消 Flush 或时间戳恢复。

Windows 已有人工功能测试；最终产物另外执行隔离数据的安装/启动、SQLite、Sync → Restore、退出/卸载及 ZIP smoke。签名、线上自动下载安装、真实 WSL 和其他平台人工验收未完成，不能以跨平台 CI 替代。这次不发布 npm、macOS/Linux 或 Legacy 安装包；这些接口的已发布版本保持不变。

审核文件中的 `ci-candidate` / `unsigned-candidate` 和 `releaseAuthorized: false` 保留公开前构建证据及未启用自动安装状态；公开版本状态以 GitHub Release 为准。
