# v1.0.1：Windows 更新功能与同步状态修复

**2026-09-11 同版本重新发布。** 补齐 Windows 安装版更新入口和“不再提醒此版本”，修复正常聊天时频繁出现“状态待刷新”。保留此前锁状态与同步诊断修复。

已经安装旧 1.0.1 的用户，请手动重新下载安装一次；版本号相同，不会弹出升级提示。原发布源码为 `30c276a585344fa3f4f8fee4066565c97981d038`，新源码及产物哈希以本页标签和随包 `release-manifest.v1.json`、`SHA256SUMS.txt` 为准；旧包校验值不适用于本次重新发布。

## 📦 下载

- 安装版：`CodexProviderSync-1.0.1-windows-x64-setup.exe`。
- 便携版：`CodexProviderSync-1.0.1-windows-x64-portable.zip`，完整解压后运行 `Codex Provider Sync.exe`。
- [官方 Release](https://github.com/Dailin521/codex-provider-sync/releases/tag/v1.0.1) 附 SHA-256、SBOM 与产物验收文件。

本版未签名，Windows 可能出现 SmartScreen 提示，请核对来源和 SHA-256。

## ⬆️ 升级说明

退出旧程序后手动安装或完整解压新版，不要仅替换 EXE。保留原有 Codex 数据和备份，无需先删除任何锁文件。

- 新安装版为后续更高版本提供“下载更新 → 确认重启安装”，不会后台下载或静默安装。
- 设置和新版弹窗可选“不再提醒此版本”；后续新版仍提醒，也可手动检查或恢复提醒。
- 便携版继续手动下载、完整解压；旧 .NET 版需重新安装 Electron，不能使用旧单 EXE 更新器迁移。
- 本次只发布 Windows x64，不发布 npm、macOS/Linux 或 Legacy 安装包。

## 修复内容

- 正常聊天追加、数据库非 Provider 字段及 WAL 更新，不再单独导致概览“状态待刷新”。真实 Provider、配置、文件集合/身份和锁变化仍检查，不跳过写入复核。
- 安装更新失败时释放重启占用状态，允许重试。
- 已确认失效的锁不再禁用同步；显示“上次操作已结束”，写入前再次检查并安全回收。
- 无法确认归属的锁显示“存储锁需要检查”，仍阻止写入，支持手动重新检查。
- 修复 Windows 读取进程启动时间时进程恰好退出的判断竞态。
- 锁阻断时诊断不再继续扫描聊天完整性，仍可导出诊断状态和日志。
- 修复备份清理与列表读取并发时可能报错的问题。
- 补齐同步失败阶段、底层错误码和关联 ID，方便定位首次失败。
- 更新 `js-yaml` 传递依赖至 4.3.2。

## 🛡 安全保障

状态检查不删锁、不修改数据；只有正常写操作在重新验证后回收已证明失效的锁，未知 owner 不强制处理。不读取 `auth.json` 或凭据；普通同步不改聊天正文、`updated_at` 或 `encrypted_content`。实际修改前仍备份，等长原地更新与时间戳恢复保持不变。

## ⚠️ 重要说明

若升级后仍显示“存储锁需要检查”，先退出其他同步/恢复操作，再重新检查。仍无法继续时请提供脱敏诊断包，不要上传认证文件、完整配置或聊天正文。操作部分完成可重试，或从备份手动回滚；本版不自动修复聊天内容。Windows 的 WSL UNC SQLite 仍仅限诊断。

## 🔍 验证结果

发布前要求最终源码 CI、Windows 安装/便携容器及隔离数据 Sync→Restore 验收通过；具体版本、SHA、哈希和容器结果以本 Release 附件为准。新增测试覆盖提醒偏好、安装失败、聊天追加与真实状态漂移，并核验更新 metadata、安装器哈希和 blockmap。

**线上跨版本下载、重启升级和数据保持尚未完成独立验收**，同版本手动重装不等于自动升级验证。没有新增签名、真实 WSL 或其他平台人工验收；Issue #95 反馈者机器上的复测仍待确认。

审计文件中的 `ci-candidate` / `unsigned-candidate` 与 `releaseAuthorized: false` 保留公开前构建证据；`updaterAuthorized` 单独记录更新渠道授权，不表示允许静默安装。公开状态以 GitHub Release 为准。
