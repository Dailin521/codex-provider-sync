# v1.0.3：会话同步与更新体验改进

此版本让 Provider 切换后的历史会话同步更可靠，也让桌面版更新更直接。

## 会话同步

- 支持最高 **128 MiB** 的会话首行元数据。
- 单个会话的首行编码、格式或大小有问题时，跳过该会话并显示原因；正常会话继续同步或切换。
- 问题会话关联的 SQLite 索引保持不变。修复数据后重新预览即可纳入。
- 修复非法 UTF-8、数组形式的 `payload`、复杂 JSON 以及 CRLF 边界导致的错误处理。
- Provider 字节等长时继续原地更新；其他有效会话使用流式复制，聊天正文保持不变。

## 桌面版更新

- 每天首次启动后约 **5 秒**自动检查一次更新；也可随时手动检查。
- 下载完成后是否重启安装由你决定。存储状态、同步写入、Watch 或恢复状态不会再禁用安装按钮。
- 更新不会替换 Codex 的会话、配置或备份数据。

## 使用提示

- “部分完成”表示正常会话已经继续处理。格式或大小问题请处理数据后重新预览；会话仍被占用或文件发生变化时，停止写入后再同步。
- Provider 信息一致后仍无法继续的旧会话，请查看 Codex 的具体报错；加密内容或模型兼容问题可能需要回到原 Provider / 账号，或新建会话。
- Windows x64 提供安装版和便携 ZIP。便携版请完整解压后运行。

## 下载

- 安装版：`CodexProviderSync-1.0.3-windows-x64-setup.exe`
- 便携版：`CodexProviderSync-1.0.3-windows-x64-portable.zip`
- [官方 Release](https://github.com/Dailin521/codex-provider-sync/releases/tag/v1.0.3) 提供校验文件。

本版为未签名 Windows x64 Electron 包。macOS/Linux Electron、npm 和 Legacy 包独立发布。
