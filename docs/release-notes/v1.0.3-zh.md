# v1.0.3：会话同步与更新体验改进

这次更新解决了“少量异常会话拖住整次同步”的问题，也让桌面版更新更快、更由你决定。已有 Codex 数据、配置和备份会保留。

## 🚀 升级后，你可以

- **让正常会话继续同步**：遇到格式、编码、大小或占用有问题的会话时，工具会跳过该会话并告诉你原因，不再让其他正常会话一起停下。
- **处理更大的会话元数据**：支持最高 **128 MiB** 的会话首行。修复异常数据后重新预览，即可将它重新纳入同步。
- **自行决定何时安装更新**：每天首次启动约 5 秒后检查更新；下载完成后，是否重启安装由你决定，不再因当前同步、Watch 或恢复状态禁用安装。

## ⬆️ 升级说明

1. 已安装 1.0.2 的用户可直接检查更新；下载完成后点击“重启并安装”。
2. 也可以退出旧程序后手动运行安装包。便携版请完整解压新 ZIP，不要只替换其中一个 EXE。
3. 不需要删除 Codex 配置、数据库、会话或备份。升级后可先打开“更新”页检查版本，再按原来的方式同步或切换 Provider。

## 🗂 会话同步怎么处理

- 出现“部分完成”时，正常会话已经完成；展开明细可看到被跳过的文件和原因。
- 格式、编码或大小问题：处理文件后重新预览，再同步。
- 文件仍被 Codex 占用或在操作中发生变化：结束相关会话后，再运行一次同步。
- Provider 信息已经一致但旧会话仍不能继续，请查看 Codex 的具体报错；原账号的加密内容或模型兼容问题仍可能需要回到原 Provider / 账号，或新建会话。

## 🔒 数据处理方式

- 工具只更新会话和索引中的 Provider 信息，不读取 `auth.json`，也不修改聊天正文、`updated_at` 或 `encrypted_content`。
- 实际写入前会创建备份；需要撤回时可以使用备份恢复。
- Provider 名称字节长度相同时直接更新元数据；其他正常会话保持聊天正文不变地复制更新。

## ⚠️ 使用前知道这些

- 超过 128 MiB、BOM 或 UTF-16 等不支持格式的首行，需要先处理后才能同步。
- 同步 Provider 信息不能保证跨 Provider 继续会话或 compact；它也不能解除原账号加密内容的访问限制。
- 本版提供 Windows x64 Electron 安装版和便携版；其他平台和旧版独立发布。

## 🔍 本版验证

- Windows 安装版和便携版均完成隔离数据的 Sync → Restore 验收。
