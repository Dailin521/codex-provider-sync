# v1.0.2：修复安装版检查更新立即失败

修复 1.0.1 Windows 安装版点击“检查更新”立即显示失败的问题。原因是更新器模块导入不兼容，网络请求尚未发出就已失败。

## 📦 下载

- 安装版：`CodexProviderSync-1.0.2-windows-x64-setup.exe`。
- 便携版：`CodexProviderSync-1.0.2-windows-x64-portable.zip`，完整解压后运行 `Codex Provider Sync.exe`。
- [官方 Release](https://github.com/Dailin521/codex-provider-sync/releases/tag/v1.0.2) 提供 SHA-256、SBOM 和容器验收文件。

本版未签名，Windows 可能显示 SmartScreen 提示，请核对来源和 SHA-256。

## ⬆️ 升级说明

**受影响的 1.0.1 安装版无法通过应用内检查发现此修复，请退出旧程序，手动安装 1.0.2 一次。** 保留 Codex 数据及备份，无需删除配置、数据库或锁文件。

新版安装版检查更新后，由用户下载，再确认重启安装；不会自动下载或退出安装。便携版仍通过下载页手动更新，需要完整解压。旧 .NET 版不能通过旧单 EXE 更新器迁移至 Electron。

本次仅发布 Windows x64 Electron，不发布 npm、macOS/Linux 或 Legacy 安装包。

## 🛡 安全保障

本次仅修正更新器加载，不改变 Provider 同步、备份与恢复。工具不读取 `auth.json` 或凭据；普通同步不改聊天正文、`updated_at` 或 `encrypted_content`。实际修改仍先备份，操作部分完成可重试或从备份手动回滚。

## ⚠️ 重要说明

检查更新成功不代表已下载或安装新版。网络或发布源异常仍可能导致检查失败。Windows 的 WSL UNC SQLite 路径仍仅限诊断；跨 Provider 的会话继续或 compact 限制不变。

## 🔍 验证结果

发布门禁包含真实 `electron-updater` 模块加载回归、最终源码 CI，以及 Windows 安装版和便携版容器启动、SQLite、隔离数据 Sync → Restore、正常退出和适用的卸载验收。正式更新渠道的两个容器还必须实际检查公开更新源，不能仅凭更新状态入口存在就通过。

具体源码 SHA、产物哈希和已通过容器结果以本 Release 附件为准。公开更新检查不等于跨版本下载、重启升级和数据保持验收；后者尚未完成独立验证。没有新增签名、真实 WSL 或其他平台人工验收。
